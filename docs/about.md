## 关于本站

本站使用 [VitePress](https://vitepress.dev/) + [Vue 3](https://vuejs.org/) 构建，所有内容以 Markdown 书写，
源码托管在 [GitHub](https://github.com/farron-cat/farron-cat.github.io)，通过 `gh-pages` 分支发布到
[GitHub Pages](https://farron-cat.github.io)。

写作原则：

- **尽量自己写一遍**：把看过的知识用自己的话复述，否则不算学会。
- **保留推导过程**：结论固然重要，但为什么得到结论更值得记录。
- **持续更新**：笔记是活文档，发现错误随时回来改。
